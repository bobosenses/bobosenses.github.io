从零开始,用最简单的方式在 GitHub Pages 上搭建一个属于自己的博客站点。

## 为什么选择 GitHub Pages

- 完全免费
- 自动部署
- 支持自定义域名
- 使用 Git 管理内容

## 使用 Jekyll

Jekyll 是一个静态站点生成器,非常适合博客:

- 使用 Markdown 写作
- 支持模板和布局
- 丰富的插件生态
- GitHub Pages 原生支持

## 开始搭建

1. 创建 GitHub 仓库
2. 配置 Jekyll
3. 编写内容
4. 推送到 GitHub

就是这么简单!
